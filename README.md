# Recipe Collection

A simple command-line recipe management application built using Python.

## Features
- Add new recipes with categories, ingredients, and instructions.
- View all saved recipes.
- Search for recipes in your collection.
- Remove recipes you no longer need/want.
- Automatic data saving and loading using Python's 'pickle' module.

## How to Run
1. Make sure you have Python installed on your computer.
2. Put 'main_recipe.py' and 'recipe.py' in the same folder.
3. Open your terminal in that folder and run:
  
   'python main_recipe.py'
